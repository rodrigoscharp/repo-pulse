# Repo Pulse

Integração leve com a **GitHub REST API** que gera um resumo da saúde dos repositórios de um usuário: linguagem, estrelas, forks, issues abertas e dias desde o último push.

📖 Documentação: https://rodrigoscharp.github.io/repo-pulse/

## Uso

```bash
# Node 18+ — sem dependências
GITHUB_TOKEN=seu_token node index.js rodrigoscharp
```

O token é opcional (aumenta o limite de requisições da API).
