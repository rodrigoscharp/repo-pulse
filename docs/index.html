Repo Pulse

Integração com a GitHub REST API que resume a saúde dos repositórios de um usuário: linguagem, estrelas, forks, issues abertas e atividade recente.

Instalação e uso

git clone https://github.com/rodrigoscharp/repo-pulse
cd repo-pulse
GITHUB_TOKEN=seu_token node index.js rodrigoscharp

Requer Node 18+. O token é opcional e só aumenta o limite de requisições.

O que ele mostra

  • Tabela com os repositórios (sem forks), ordenados pelo push mais recente
  • Total de estrelas
  • Quantos repositórios tiveram atividade nos últimos 30 dias

Suporte

Abra uma issue.
